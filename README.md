📌 Sobre o projeto
O Agendamento de Salas é um projeto acadêmico desenvolvido para a disciplina de Sistemas de Informação, na Universidade da Região de Joinville (Univille).

A aplicação tem como objetivo facilitar o gerenciamento de salas, permitindo consultar a disponibilidade de espaços e organizar reservas de forma prática e eficiente.

A proposta busca otimizar a utilização dos ambientes, melhorar a organização dos horários e evitar conflitos de agendamento.

🎯 Objetivos
📅 Facilitar a consulta de disponibilidade das salas.
🏢 Organizar o gerenciamento e a reserva de espaços.
⏰ Evitar conflitos entre agendamentos.
✅ Tornar o processo de reserva mais simples e eficiente.
